# 🕒 **Little Clock**

Una pequeña aplicación web que muestra la hora actual con una estética de reloj analógico y digital, inspirada en un reloj de pared moderno.

![Preview](./public/resources/images/Rainy%20Night.webp)

---

## ✨ Características

* 🕐 Reloj analógico con manecillas (hora, minuto, segundo)
* ⏱️ Reloj digital en tiempo real
* 🎨 Estética visual moderna (neón + fondo desenfocado)
* 📱 Diseño responsive
* ⚡ Actualización dinámica con JavaScript

## 🌿 Ramas (Git)

El proyecto se organiza utilizando ramas tipo `feature`:

* `main` → rama principal
* `develop` → rama desarrollador
* `feature/page` → estructura HTML
* `feature/style` → estilos CSS
* `feature/script` → lógica en JavaScript
* `feature/improve` → mejoras y optimizaciones

## 🎯 Objetivo del proyecto

Este proyecto fue creado con fines de práctica para:

* Manipulación del DOM
* Uso de `transform` y animaciones en CSS
* Manejo del tiempo con JavaScript
* Organización de proyectos con Git y ramas

---

## 📸 Vista previa

La interfaz combina un reloj analógico con un formato digital:

* Colores diferenciados para cada unidad de tiempo
* Fondo con efecto visual tipo *glassmorphism*
* Diseño centrado y minimalista
